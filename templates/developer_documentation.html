Developer Documentation

Maintainer-focused reference for architecture, setup, core flows, data model, and route inventory.

Architecture

  • Backend: Flask app with server-rendered Jinja templates.
  • ORM: Flask-SQLAlchemy models in eco_basket/models.py.
  • Routing: App routes are registered from eco_basket/routes.py.
  • Session Auth: User/admin session guards are in eco_basket/auth.py.
  • Catalog Source: Product catalog lives in plants.py and is enriched in eco_basket/catalog.py.

Key Features

  • Secure auth with password hashing.
  • Wishlist sync (localStorage + server persistence), cart, coupon and loyalty flow.
  • Delivery -> payment -> order success checkout pipeline.
  • Order history, returns workflow, support tickets, chatbot, and full admin portal.

Data Model

Model Purpose Important Fields
Store User accounts id, name, email, password
CartItem User cart entries user_id, plant_id, quantity, unit_price
Order Placed orders and payment state user_id, plant_id, quantity, grand_total, payment_status, order_status
SupportTicket Complaint and support workflow reference_code, category, priority, status, assigned_agent
