Data Model Summary

Model Purpose Key Fields
Store User account and authentication id, name, email(unique), phone_number, password(hash)
Order Checkout, payment, and order lifecycle user_id, plant_id, quantity, grand_total, payment_status, order_status
SupportTicket Customer complaints and agent workflow reference_code, category, priority, status, assigned_agent

Checkout and Payment Flow

  1. User selects a plant and quantity from /plant/<plant_id>.
  2. Address is captured at /deliveryinfo and a server-side Order is created.
  3. Payment method is submitted at /payments with CSRF-protected form data.
  4. COD marks order as pay_on_delivery; online flow goes through /process_payment and /payment_success.
  5. Final confirmation is rendered at /ordersuccess.
